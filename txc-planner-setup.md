# TechXchange 2026 Planner: offline app for iPhone and iPad

Everything below can be done from the iPad in Safari. It takes about 10 minutes.

## 1. Create a GitHub account (2 min)
1. Go to **github.com/signup** in Safari.
2. Enter your email, a password and a username.
   The username becomes part of your app's address: `https://USERNAME.github.io/...`
3. Solve the puzzle, then enter the code GitHub emails you.
4. Choose the **Free** plan.

## 2. Make the repository (2 min)
1. Tap **+** (top right) → **New repository**.
2. Name: `txc-planner`
3. Leave it **Public**. Free GitHub Pages needs a public repository. It only holds the public session catalog; your picks never leave your device.
4. Tick **Add a README file**, then **Create repository**.

## 3. Upload the files (3 min)
1. In the Files app, tap the zip you downloaded to unzip it.
2. In the repository, tap **Add file → Upload files → choose your files**.
3. Select all six files from the unzipped folder:
   `index.html`, `sw.js`, `manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png`
4. Tap **Commit changes**.

## 4. Turn on GitHub Pages (1 min)
1. Open the repository's **Settings → Pages**.
2. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
3. Wait 1–2 minutes and refresh. The page shows your address:
   **`https://USERNAME.github.io/txc-planner/`**

## 5. Install it on the iPhone or iPad (1 min)
1. Open that address in **Safari**. It must be Safari, not Chrome.
2. Tap **Share → Add to Home Screen → Add**.
3. Open **TXC Planner** from the new icon once while online, then close it.

From then on it works with no signal, including in flight mode. Picks, filters, sort and theme are saved on that device.

## Updating later
Upload a new `index.html` over the old one in step 3. The app picks it up the next time you open it online, and shows it the time after that.

Note: each device keeps its own picks, so an iPhone and an iPad installed separately won't share them.
